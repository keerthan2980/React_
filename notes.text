                             Async and Await 
In React, async and await are used to handle asynchronous operations, such as fetching data from an API or performing some background task without blocking the main thread. 
They allow you to write asynchronous code in a way that looks synchronous, making it easier to understand and maintain.

async Function:

The async keyword is used to define a function that returns a Promise("statement or the data). Inside this function, you can use the await keyword.

await Keyword:

The await keyword can only be used inside an async function. It pauses the execution of the function until the Promise(before statement or data is completed) 
it is waiting for is resolved or rejected.
                                code 
async function fetchData() {
  const response = await fetch('https://api.example.com/data');
  const data = await response.json();
  console.log(data);
}
